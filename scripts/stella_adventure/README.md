# 다섯 스텔라 직접 조작 본게임 반영

2026-11-18. 후와의 승인된 화면·조작 구조로 도리·유네·단밍·쿠비·야토의 책을 본게임에 연결했다. `growth_game.gd`가 에테의 의뢰·책 입장·저장·해금을, `game.gd`가 이동·행동·장면 진행을 담당한다. `chapters.gd`는 공식 사건 대응과 저장 검증, `art.gd`는 기존 전신 도트와 소품 연출이다. 후와의 탐색·귀환은 기존 구현을 유지한다.

## 적용된 플레이

| 직접 조작 | 행동과 변화 | 공식 사건 보존 |
|---|---|---|
| 도리 | 돌 둔갑/해제, 두 자리 잠복, 잠듦, 에테의 운반, 도서관에서 설명 | 돌로만 변함, 에테의 애완돌 착각, 즉흥 추리가 우연히 맞음. 범인·정답은 창작하지 않음 |
| 유네 | 움직이는 악몽 먹기, 좋은 꿈 지키기, 꿈빛이 줄어드는 공간 이동, 외부 빛 따라 문으로 | 꿈 감소는 플레이 실패 때문이 아님. 몽치가 꿈이나 빛을 만들어 구하지 않음 |
| 단밍 | 같은 화살의 먼지·두 깃을 드래그/E 유지로 정돈, 반복 일상, 뜻밖의 부름 | 작업 성공으로 소환된다는 인과 없음. 취업·잡무·무기력·우연한 부름 유지 |

WASD·방향키/바닥 클릭 이동, E/대상 클릭 행동, Esc 정지, F5 저장, Q/책 덮기 복귀. 돌로 둔갑한 동안에는 움직일 수 없고 E로 해제한다. 악몽 먹기와 빛 집중은 E 유지 또는 가까운 대상 클릭으로 진행한다. 화살 손질은 작업대 위 드래그 또는 E 유지로 진행하며, 포인터가 잠시 벗어나도 완료 부분은 유지된다. 이동 입력은 클릭 경로와 작업을 취소한다.

## 저장과 합류

선택적 `stella_adventures` 필드에 멤버별 장면·완료 행동·좌표·안내 확인 여부를 저장한다. 버전·허용 장면·행동 비트·유한 좌표를 검증한다. 막간 연출은 해당 장면부터 안전하게 재생하고, 미완료 연속 동작의 수치는 재시작한다. 완료한 화살 부분 등 이산 행동은 보존한다. 구형 저장은 대응하는 공식 사건으로 연결하며 완료한 책은 그대로 유지한다.

도서관 도착 연출이 끝나기 전에는 주민을 해금하지 않는다. `complete_stella_adventure`는 도착 상태·현재 의뢰·미완료 조건을 검사한 뒤 기존 책 완료 경로를 사용한다. 중복 호출은 무효다. 재체험은 별도 진행으로 주 저장을 바꾸지 않는다. 플레이어의 팬 모습, 도서관 시간, 골드·기억의 빛은 책 플레이로 바뀌지 않는다. 어떤 멤버가 마지막이어도 첫 재건만 시작하며 시설·재개관을 자동 완료하지 않는다.

## 확인과 남은 평가

- `tests/stella_production.gd`: 다섯 편 실제 입력 완주, 해금 시점, 디스크 이어하기, 재체험, 실제 주민 등장.
- `tests/stella_edgecases.gd`: 네 방향, 벽, 포커스 이탈, 구형 저장, 화살 일부 손질 중 저장, 각 멤버의 여섯 번째 합류.
- `tests/growth_production_flow.gd`: 에테 의뢰부터 전원 합류·재건·재개관·홍보·방문·구매·이어하기·반납.
- 기존 후와 통합 검사와 저장 경로 검사도 수행한다.
- 실제 렌더·960×600 화면은 `artifacts/stella_adventures_20261118/`에 보관한다. 얼굴·신체를 분리 변형하지 않고 기존 전신 프레임과 발 기준점을 사용한다.

자동 입력 완주는 초회 플레이타임이나 재미 평가를 대신하지 않는다. 사용자 첫 플레이 후 잠복 길이, 꿈 이동 속도, 안내 빈도와 각 편의 분량은 추가 조정할 수 있다. 이번 반영은 공식 사건을 직접 행동으로 경험하는 첫 통합이며 장편 스토리 확장이나 새 공식 사건 추가가 아니다.

## 2026-11-19 브라우저 플레이 피드백 점검

사용자가 표시 시안을 승인하여 본게임에 반영:

- 도리의 돌 운반 장면: 기존 왼쪽 전용 들기 그림을 오른쪽 이동에도 사용하던 문제를 수정했다. 승인된 원화의 좌우 측면으로 들기 프레임을 별도 생성하며 실제 이동 거리로 걸음을 진행한다. 돌을 줍는 동안과 도착 뒤에는 걷기를 멈춘다. 공식 사건, 연출 시간, 도착 위치는 유지한다.
- 기본 텍스처 보간을 Nearest로 설정했다. 별도 필터가 없던 초상화 등에 적용되던 Linear 확대의 흐릿함을 제거한다. 원본 얼굴과 신체 비율을 재작성하거나 해상도에 맞춰 찌그러뜨리지 않는다. 작은 화면의 세부 정보 감소까지 없애는 수정은 아니다.
- `tests/story_feedback.gd`의 이동 방향·정지·거리 연동·전신 프레임 경계 검사, 기존 다섯 편 진행 160항목·경계 94항목·후와 36항목 통과.
- 별도 프로필의 로컬 Chrome으로 PC 1280×800 및 모바일 모의 화면 844×390/DPR 2의 시작·대화 렌더링 확인. 두 환경에서 실제 수첩→에테 의뢰→단밍 책 진입 후 이름표를 각각 마우스 클릭/모의 터치하여 작업대 장면으로 넘어가는 화면까지 확인했다. 모바일 캔버스는 1688×780으로 출력된다. 실제 휴대전화 터치 완주를 확인한 것은 아니다.

상호작용 표시 반영:

- 기존 표시가 1픽셀 반투명 선에 가까워 배경 무늬에 묻히는 것을 여섯 편에서 확인했다.
- 승인받은 짙은 외곽선·바닥 발판·행동 이름을 `scripts/story_markers.gd`로 공유하고 여섯 편의 실제 장면에 적용했다. 발판과 이름표를 같은 좌표 기준으로 판정해 클릭/터치하면 해당 지점으로 이동하여 기존 행동을 이어간다. 캐릭터는 표시보다 앞에 그린다.
- 순서가 있는 장면은 현재 할 행동만 표시한다. 완료·설명·일시정지·자동 연출 중에는 불필요한 표시를 숨긴다. 단밍의 화살 부위를 일부 손질해도 작업대 표시는 유지한다.
- 도리의 돌 둔갑을 풀 수 있는 이름표, 단밍의 부름 장면에서 키보드 없이 누를 수 있는 진행 버튼을 연결했다. 후와는 실제로 텐비가 보일 때만 만남 표시가 나오며 귀환술 표시는 기존 귀환 연출을 시작한다.
- `tests/story_markers.gd`: 표시·이름표 가장자리 입력·다음 행동 공개·부분 작업 재개·도리 둔갑 해제·후와의 숨은 텐비 위치 보호·귀환술 및 다섯 편 포인터 입력 완주를 포함해 174항목 통과.
- 본게임 적용 화면과 작은 창 캡처는 `tests/story_markers_visuals.gd`로 확인한다. 비교 화면과 검사 기록: `artifacts/tester_feedback_20261119/`.
