# 후와편 본게임 연결

2026-11-18 승인 반영. `game.gd`, `art.gd`, `return_flow.gd`는 승인된 탐색·귀환 연출을 공유한다. `campaign.gd`와 `growth_game.gd`가 저장·해금·도서관 복귀를 연결한다. 기존 시안 파일은 이 공통 구현을 상속하며 저장·해금은 하지 않는다.

에테에게 후와 의뢰를 받고 책에 들어가면 후와를 직접 조작한다. WASD·방향키/클릭 이동, E 살피기·재회·귀환술, Esc 정지, F5 저장, Q 또는 ‘책 덮기’로 복귀한다. 본게임에서는 시안의 R 초기화를 막는다.

도서관에서 눈뜨는 연출이 끝나야 후와의 책과 주민·텐비 변신을 해금한다. 도착 후 E로 실제 도서관에 돌아간다. 골드·기억의 빛·시설은 지급하지 않으며, 여섯 번째 합류는 첫 재건으로 이어진다. 도착 연출용 배경과 실제 운영 도서관의 재건 상태는 별개다.

선택적 저장 항목 `fuwa_adventure`는 허용 단계·좌표 범위·유한 수 검사 후 사용한다. 공터 진입과 재회에 구간을 자동 저장하고, F5·책 덮기·창 닫기에도 저장한다. 귀환 연출 도중 저장은 재회 직후부터 이어간다. 기존 미완료 책은 대응 구간으로 연결하며, 이미 완료한 책은 해금을 유지한다. 재체험은 본 진행과 분리한다.

신사 수련은 도입 문장으로 전달한다. 후와가 텐비를 찾고 귀환술을 쓴 뒤 뜻밖의 균열을 거쳐 도서관에 도착하는 공식 사건 순서를 유지한다. 실종 이유나 균열 원인은 추가하지 않는다. 술식 모양·엄폐·순찰·눈발·대사는 게임용 연출이다.

검사: `tests/fuwa_production.gd`, `tests/growth_production_flow.gd`, `tests/growth_save_routing.gd`, `tests/fuwa_search_preview.gd`. 실제 이동, 저장/이어하기, 구형 저장, 중복 해금 방지, 여섯 번째 합류 및 기존 다섯 편부터 영업까지 확인한다. 검사 저장은 `artifacts/` 전용 경로만 사용한다.
